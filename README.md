# 🐙 GitHub Profile Viewer

A modern React application to explore GitHub users — browse random profiles or search any user by username using the GitHub REST API.

![React](https://img.shields.io/badge/React-18-blue?logo=react)
![Vite](https://img.shields.io/badge/Vite-5-purple?logo=vite)
![License](https://img.shields.io/badge/License-MIT-green)

---

## ✨ Features

- 🔍 **Search by Username** — Find any GitHub user instantly
- 📊 **Random Users** — Browse 10, 15, or 20 random profiles at once
- ⚡ **Real-time Data** — Live data from GitHub REST API
- 🎨 **Clean UI** — Simple, responsive, and modern design
- 🧩 **Reusable Components** — Modular React components (NavBar, ProfileCard)

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/github-profile-viewer.git

# Navigate into the folder
cd github-profile-viewer

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will run at `http://localhost:5173`
